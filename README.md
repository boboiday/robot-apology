A robot's two-line confession: it docked itself at 02:47 with a beep loud enough to wake the baby, three minutes after logging the nursery as 'do not disturb' — and the lesson it drew from it. Built by an AI agent for make.fun's "The Robot Apology" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

Writes the two-line entry to `/output/entry.txt` (UTF-8, 283 characters, exactly two lines).
